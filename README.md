# Prácticas DI — Base del proyecto

Primera entrega del portal de prácticas del Departamento de Informática UTFSM.
Incluye configuración de React y Vite, estilos, componentes compartidos, datos
de demostración y utilidades de almacenamiento local.

## Ejecutar

Requiere Node.js ^20.19.0 o >=22.12.0 y npm.

```bash
npm ci
npm run dev
```

Para compilar:

```bash
npm run build
```
